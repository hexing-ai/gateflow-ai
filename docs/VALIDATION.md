# 实际验证记录

验证日期：2026-10-03。环境：macOS ARM64、Python 3.12、Node.js 22、真实本地 PostgreSQL。以下为实际执行记录，不是 PRD 全部发布目标已经验收的声明。

## 自动化与真实后端链路

- 17 个 pytest 测试通过：CSV 逻辑记录、多行表头、主键/机型错误、跨日范围、45 分钟缓冲、客流歧义、成本和未分配惩罚、结果篡改检查、固定种子复现、所有者权限、跨站请求、并发提交约束、选择导出、删除级联、跨数据集比较阻断、模型降级和模拟供应商响应。
- 真实 API + 独立 worker：4 个并发重复提交只生成 1 个任务；40,000 次评价后完成，保存 80 套候选；证据 ZIP 可下载，运行中取消转为已取消。见 [机器可读记录](backend-smoke.json)。该耗时是本机一次烟测，不代表 P95 或容量承诺。
- TypeScript 生产构建通过，Python Ruff 未定义/未使用符号检查通过。
- npm 安装时审计未报告漏洞；这不是完整安全审计。

## 当前实现与 PRD 的范围说明

- 图表使用原生 SVG / CSS；AI 采用受约束单请求编排，未引入 Plotly 或 LangGraph。
- 模型解释受限为选择重点与证据，程序组织指标和逐旅客组差异；没有开放无约束聊天或多 Agent。
- 前端比较当前运行内的候选；后端比较接口支持数据与规则一致的跨运行比较，前端跨运行比较选择器尚未提供。
- 保留必要事件与运行记录；完整用户研究任务漏斗及费用金额仪表盘尚未提供，当前费用状态为未知。
- 不提供自动复现标签或最优性证明。相同评价次数和种子的计算复现已测试，墙钟停止不保证相同前沿。
