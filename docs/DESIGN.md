# 视觉与交互设计

GateFlow 采用航空运行决策台布局，服务于“看清安排、比较方案、复核依据”这一任务。首屏由紧凑导航、单行指标、航站资源示意、时间轴和右侧解读组成。

## 视觉系统

| 用途 | 颜色 |
| --- | --- |
| 导航与品牌 | `#10273B` |
| 工作区底色 | `#F1F5F8` |
| 数据画布 | `#FFFFFF` |
| T 厅与主要操作 | `#3268EC` |
| S 厅与负向成本差额 | `#158E91` |
| 待处理事项 | `#BF8024` |

中文使用系统中文字体，英文采用可用的 IBM Plex Sans / Avenir Next 回退，关键指标采用系统数字字体，航班和口位使用等宽字体。字体不依赖外部网络加载。除颜色外，航站名、口位名、斜线缓冲与虚线未使用状态也承载含义。

## 信息结构与交互

- 指标并排展示分配率、未安排固定口、使用口数及中转成本，保持同一方案口径。
- 上方方案标签与候选表共用当前方案状态，切换同步更新各视图。
- 航站资源标记按完整方案是否使用着色；点击可筛选时间轴。背景不表示实时飞机停靠。
- 资源示意可折叠，时间轴支持航站筛选、单口聚焦和完整运行日视图。
- 右侧概览明确比较对象，展示当前方案减去参考方案的差额。参考方案优先取已勾选且不同于当前的方案，其次取其他候选。
- 比较视图保留 2–3 套方案的计算证据摘要、逐旅客组路径差异与问题入口。
- 窄屏使用折叠导航、两列指标和单列主区；时间轴与表格局部滚动。键盘焦点可见，弹窗支持 Escape 和焦点回退，遵循减少动画偏好。

## 视觉来源

布局观察参考 [INFORM](https://www.inform-software.com/en/solutions/aviation-ground-operations/airport-resource-management) 的官方时间轴与详情展示，以及 [Copenhagen Optimization](https://copenhagenoptimization.com/better-airport/better-stand-gate) 的资源占用示意。完整观察见 [竞品分析](COMPETITIVE_ANALYSIS.md)。没有使用竞品图片作为产品素材。

`web/public/terminal-apron.jpg` 是本项目通过内置图像生成工具制作的建筑示意，原始尺寸 2172 × 724，网页使用压缩 JPEG。提示词核心要求：两座并列的低层航站楼、各六条廊桥、白色铝板与浅蓝玻璃、蓝色/青色建筑装饰、浅色停机坪、轴测视角、无文字无飞机无真实机场标识。口位文字与状态由 HTML 叠加，不写入图片；资源数量较多时口位按钮转入扩展列表。
