# GateFlow 视觉方向

主题：机场计划分析工作台。主要任务：在有限资源与中转成本之间选择可解释的分配方案。

配色：航图深蓝 #102c46、交互蓝 #2478d4、航站青 #168c90、雾蓝 #eef3f8、纸白 #ffffff、告警琥珀 #ad6c19。
字体：标题用 Avenir Next / 系统无衬线；中文正文 PingFang SC / Microsoft YaHei；时刻和数量用 SFMono-Regular / Consolas。均使用系统字体，无外部字体请求。
布局：固定侧栏 + 工作区 + 可收起解读面板。上部展示运行日与分析对象，中部以真实分配甘特图为核心，下部比较候选和中转变化。
标志性元素：航站楼鸟瞰示意与真实分配时间轴共同呈现，跨厅用蓝/青区分，缓冲用斜线纹理，避免把缓冲伪装成占用。
交互：候选切换使指标、时间轴和解释同步更新；键盘可操作；尊重 reduced-motion；窄屏将导航和侧栏转为纵向。
公开版边界：合成样例和预计算明确标注。不会伪装实时求解或模型对话。
